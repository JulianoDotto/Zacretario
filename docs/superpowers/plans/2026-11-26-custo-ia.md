# Custo da IA do Zacretário — Plano de implementação (roteiro guiado)

> **Para quem executa:** este plano roda no **modo copiloto (quack)**, não em subagentes. Cada Task é uma etapa: antes de começar, o Claude pergunta **"Eu faço"** ou **"Claude faz"** e recomenda uma das duas. A recomendação é "Eu faço" na primeira vez de um tipo de coisa e "Claude faz" quando é repetição. Passos com segredo, login ou conta (Google, Groq, console da Anthropic) são sempre do usuário. Depois de cada passo o Claude confere de verdade, lendo a execução, o banco ou a página, e registra a etapa no diário. Passos usam checkbox (`- [ ]`).

**Objetivo:** baixar o custo por mensagem do agente, medido com antes e depois, e manter o bot funcionando quando o Claude falhar.

**Arquitetura:** uma pessoa de teste (`teste`), com agenda Google própria, isola os testes. Um conjunto fixo de mensagens roda direto no workflow **Agente Zacretário**, e os resultados e tokens de cada rodada vão para uma tabela. A configuração muda em fases: linha de base, Sonnet ajustado e Haiku. O fallback é um *Groq Chat Model* ligado ao AI Agent.

**Tecnologias:** n8n (AI Agent 3.1, Anthropic Chat Model 1.6, Groq Chat Model), Claude Sonnet 5.5 / Haiku 5.5, Groq (plano grátis), Postgres, MCP do n8n.

**Spec:** [`docs/superpowers/specs/2026-11-26-custo-ia-design.md`](../specs/2026-11-26-custo-ia-design.md)

## Restrições globais

- Os testes rodam **só** com `user_key = 'teste'` e a agenda "Zacretário teste". Nunca com `juliano` nem com a pessoa da Bruna.
- Nada de chave, telefone real ou `calendar_id` real no repositório. O `whatsapp_id` da pessoa de teste é falso: `teste-sem-whatsapp`.
- Raciocínio do Sonnet 5.5: nunca `thinkingMode: disabled`, que dá erro 400. Usar `adaptive` com `effort`.
- Cache: `promptCaching: 5m`.
- Modelos: `claude-sonnet-5-5` (atual) e `claude-haiku-5-5` (candidato).
- O Haiku só vira principal se passar em **todos** os testes marcados como ⚠️ (confirmação e datas).
- O fallback não pode ser um provedor que treine modelos com as conversas (`PRIVACY.md`).
- Preço para as contas (US$ por milhão de tokens): Sonnet 5.5: entrada 2, saída 10, leitura de cache 0,10, gravação de cache de 5 min 2,50. Haiku 5.5: entrada 0,10, saída 0,50, leitura de cache 0,01, gravação de cache de 5 min 0,125. Antes da Task 3, conferir na página de preços da Anthropic se os valores de cache do Haiku estão certos.
- Cada etapa termina com uma entrada no diário do quack. As etapas com números entram também no `docs/learning-log.md`.
- Commits só com aprovação do usuário, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Foco da revisão

1. **Estado que vaza de uma rodada para a outra** (histórico, TODOs ou eventos da rodada anterior mudam as respostas) → toda rodada começa com o reset da Task 2. O teste 1 de cada rodada confere que a agenda e os TODOs estão vazios.
2. **Teste chegando na agenda real** (regra do Switch errada, `calendar_id` = `primary`) → a Task 1 cria um evento pela pessoa `teste` e confere que ele aparece **só** na agenda de teste.
3. **Mudança de configuração atingindo a Bruna no meio dos testes** (sub-workflows rodam a versão publicada) → a Task 2 descobre se o MCP roda o rascunho ou a versão publicada, e as Tasks 4 e 5 seguem essa resposta.
4. **Datas relativas que dependem do dia em que o teste roda** ("quinta", quando hoje é quinta) → o resultado esperado é escrito como regra ("a próxima quinta, ou hoje se ainda não passou da hora"), não como data fixa.
5. **Fallback pulando a confirmação** → o teste de cancelar faz parte da rodada do fallback na Task 6, e o resultado fica registrado como risco conhecido.

- [x] **Passo 2:** escrever o reset. O SQL fica assim:
  ```sql
  DELETE FROM conversation WHERE user_key='teste';
  DELETE FROM todos WHERE user_key='teste';

O `user_key` fixo garante que nenhum teste rode como outra pessoa.
- [x] **Passo 4:** descobrir se esse *Execute Workflow* roda o rascunho ou a versão publicada do **Agente Zacretário**. - [x] **Passo 5:** exportar **Testes do agente** para `workflows/testes-do-agente.json`. Commit `test: agent evaluation set`.
  - *Feito assim:* o reset do banco virou um segundo gatilho (**Resetar teste**) no próprio **Testes do agente**, e a agenda é limpa pelo conector do Google Agenda.
